# پوشه فونت‌های پنل مدیریت اسراء

فایل‌های فونت یکان بخ (نسخه اعداد فارسی) را با نام‌های زیر در این پوشه قرار دهید:

1. `YekanBakhFaNum-Regular.woff2` (وزن عادی - ۴۰۰)
2. `YekanBakhFaNum-Bold.woff2` (وزن ضخیم - ۷۰۰)

در فایل CSS برنامه (`src/index.css`) دستورات `@font-face` و در فایل `index.html` تنظیمات پیش‌بارگذاری (preload) قرار داده شده است و به محض کپی کردن فایل‌ها در این مسیر، سامانه به صورت خودکار از آن‌ها استفاده خواهد کرد.
